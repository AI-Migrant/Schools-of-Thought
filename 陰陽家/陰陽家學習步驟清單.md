## 預備篇：閱讀前須知

**“十二家”從哪裡來？**  
西漢司馬談在《論六家要旨》中最早把先秦諸子概括為陰陽、儒、墨、名、法、道德六家，這篇文章由其子司馬遷收進《史記·太史公自序》。東漢班固編《漢書·藝文志》，依據劉向、劉歆父子的圖書整理成果，將諸子分為儒、道、陰陽、法、名、墨、縱橫、雜、農、小說十家，又說“諸子十家，其可觀者九家而已”——小說家不算大道，故有“九流十家”之稱。後世通行的“十二家”口徑，一般是在十家基礎上增入兵家與醫家而成。**陰陽家始終穩居其中**，是諸子中最“靠近自然”的一家：它研究天文、曆法、時令與災異，並以此解釋人事與政治。

**為什麼陰陽家值得單獨學？**  
因為它是中國古代“自然哲學”的主要承擔者：五德終始說塑造了此後兩千年王朝合法性敘事的框架，陰陽五行則沉澱為中醫、曆法、風水、命理共同的底層語言。學懂陰陽家，等於拿到一把理解中國傳統文化的鑰匙。

**一個必須先記住的事實**  
陰陽家的集大成者鄒衍，其著作（《鄒子》四十九篇、《鄒子終始》五十六篇，見《漢書·藝文志》著錄）**全部亡佚**。今天所知的鄒衍學說，全靠《史記》《呂氏春秋》等書的轉述與後人輯佚。這意味著學習陰陽家，一半功夫在“學說”，另一半功夫在“如何從二手材料重構學說”——這本身就是一次極好的史學訓練。

## 階段一：概念地基——先弄懂三個詞

> 陰陽家的所有學說都建立在「陰陽」「五行」「氣」三個概念之上。零基礎者最常犯的錯誤，是帶著現代印象（玄學、算命、養生話術）去理解它們。本階段的目標是把這些詞放回先秦語境，恢復它們本來的樣子——它們首先是一套解釋世界的分類與推演工具。

### 步驟 1：什麼是“陰陽”

**學習目標**：能用自己的話說清陰陽的本義與引申義，不再把它當成神秘符號。

**子主題**

- [ ] 陰陽的日常本義：向日為陽、背日為陰（山南水北為陽，山北水南為陰）。《詩經·大雅·公劉》「既景乃岡，相其陰陽」是“陰陽”連用的最早出處，說的只是山坡的向背——陰陽最初是個地理詞
- [ ] 從具體到抽象：日光向背推及寒暑、晝夜、動靜、進退、男女——陰陽成為一種**關係分類法**，凡相對待、相反相成者皆可名之
- [ ] 關鍵認識：陰陽描述的是**關係**而非**兩種實體**。同一事物在一種關係中為陽，在另一種關係中可為陰（如晝對夜為陽，晝中之午對晨又為陽中之陽）
- [ ] 陰陽的三條基本規律：對立制約、互根互用、消長轉化（註：這套規範化表述定型較晚，多見於後世醫書與易學，作為入門框架卻十分合用）

**配套原典**（短小，先讀白話，再回看原文）

- 《老子》第四十二章：「萬物負陰而抱陽，沖氣以為和」——萬物皆含陰陽兩面
- 《莊子·天下》：「《易》以道陰陽」——點明《周易》與陰陽的對應關係
- 《周易·系辭上》：「一陰一陽之謂道」——陰陽被提升為宇宙根本法則

**自測**

1. 用「向背」原理解釋：洛陽、衡陽二城為什麼以「陽」命名？
2. 「陰陽是關係而非實體」——舉一個例子說明同一事物可以既是陽又是陰。

### 步驟 2：什麼是「五行」

**學習目標**：掌握五行的原始含義、生克關係與配伍系統，並能說出它與古希臘「四元素」的本質區別。

**子主題**

- [ ] 五行最早出處：《尚書·洪範》「五行：一曰水，二曰火，三曰木，四曰金，五曰土。水曰潤下，火曰炎上，木曰曲直，金曰從革，土爰稼穡」——注意：這裡說的是**五種功能類別**（潤下、炎上皆是性質描述），不是「構成萬物的五種物質」
- [ ] 五行不等於四元素：古希臘四元素說回答「世界由什麼構成」，五行回答「事物如何分類、彼此如何作用」——前者是構成論，後者是功能與關係論
- [ ] 兩大關係：**相生**（木生火、火生土、土生金、金生水、水生木）與**相勝**（木勝土、土勝水、水勝火、火勝金、金勝木；後世亦稱相克）
- [ ] 配伍系統：五行一旦成立，便開始與五方、五色、五味、五帝、四時等一切「五」系列掛鉤——這是理解後世一切陰陽五行學說的樞紐
- [ ] 先秦人的靈活態度（擴展）：《孫子兵法·虛實》「五行無常勝，四時無常位」——相勝並非絕對，視條件而定

**任務**

- [ ] 默畫「五行相生相勝圖」（外圈相生、五角星相勝），練到不假思索
- [ ] 填一張五行配伍表：木火土金水 × 五色、五方、五味、四季

**配套原典**：《尚書·洪範》五行段；《孫子兵法·虛實》末段

**自測**

1. 「金曰從革」是什麼意思？
2. 水為什麼既能「生」木、又能「勝」火？兩種關係有何不同？

### 步驟 3：合流——陰陽、五行與「氣」

**學習目標**：理解陰陽與五行本是兩套獨立起源的系統，以及它們如何被「氣」黏合為一體。

**子主題**

- [ ] 兩套系統的不同出身：陰陽源於日光向背與歷法觀察，五行源於《洪範》式的事物分類——先秦早期文獻中二者起初各說各話
- [ ] 合流的場所：戰國齊國的稷下學宮。《管子》中的《幼官》《四時》《五行》諸篇，將四時、五行、方色、政令編成一張大表，被視為兩套系統合流的最早樣本（學界主流看法，可參考白奚《稷下學研究》）
- [ ] 「氣」的黏合作用：陰陽是氣之兩端的消長，五行是氣之流行的循環——氣論讓陰陽五行從靜態分類表升級為動態宇宙圖式
- [ ] 用一張圖總結：氣分陰陽 → 陰陽消長為四時 → 四時配五行 → 五行生克化生萬物

**任務**：畫一張「陰陽—五行—氣」關係圖，向朋友講解三分鐘。

**現代論著**：白奚《稷下學研究》相關章節；梁啟超《陰陽五行說之來歷》（對合流過程做過著名的批判性清理，讀時保持辨析態度）

**自測**：陰陽與五行哪一套起源更「貼近自然觀測」？二者的合流發生在何時何地、依靠哪個概念完成？

## 階段二：學派源流——陰陽家是誰

> 了解了陰陽五行的概念，還要知道將它們組織成學派的是誰。本階段解決三個問題：陰陽家在諸子圖譜中處於什麼位置？它源自哪些古老的職業傳統？它的集大成者鄒衍是怎樣的人？

### 步驟 4：諸子圖譜中的陰陽家

**學習目標**：能復述「六家 → 十家 → 十二家」的譜系，並背出正史對陰陽家的兩句經典評價。

**子主題**

- [ ] 譜系三跳：司馬談《論六家要旨》分六家（陰陽、儒、墨、名、法、道）→ 班固《漢書·藝文志》分十家（儒、道、陰陽、法、名、墨、縱橫、雜、農、小說）→ 通行的「十二家」再增兵家、醫家
- [ ] 陰陽家的畫像：《漢書·藝文志》說這一派「蓋出於羲和之官」（上古掌觀象授時的天文曆法官），其長處在「敬順昊天，歷象日月星辰，敬授民時」
- [ ] 兩句必背的評語：
- 司馬談：「嘗竊觀陰陽之術，大祥而眾忌諱，使人拘而多所畏；然其序四時之大順，不可失也。」——弊在禁忌繁瑣，功在安排農時
- 班固：「及拘者為之，則牽於禁忌，泥於小數，舍人事而任鬼神。」——末流之弊
- [ ] 一句話定位：陰陽家是諸子中的「自然知識專家」，它為亂世提供的方案是「天與人如何同步」

**配套原典**：《史記·太史公自序》載《論六家要旨》陰陽家段；《漢書·藝文志·諸子略》陰陽家小序

**任務**：做一張十二家一覽表（家派、代表人物、核心主張各一欄），把陰陽家那一行加粗。

**自測**：陰陽家出於什麼官守？其學說之「長」與「弊」各是什麼？

### 步驟 5：從羲和之官到稷下先生——學派的來歷

**學習目標**：理清「官學 → 私學」的演變線索，明白陰陽家如何從王官職業知識變為民間學派。

**子主題**

- [ ] 上古的知識壟斷：觀測天象、制定曆法、解釋災異，本是王官的專業職能；上古傳說「絕地天通」（《國語·楚語下》）反映的正是通天之權收歸官守的古老記憶
- [ ] 春秋戰國的「知識下移」：周室衰微，王官之學散入列國，掌握曆法星占之術的士人開始周遊列國、自售其學
- [ ] 齊國稷下學宮：戰國百家爭鳴的主戰場，陰陽五行之說在此與儒、道、名、法各家交鋒融合，最終成家
- [ ] 陰陽家的著錄陣容（擴展）：《漢書·藝文志》陰陽家共著錄「二十一家，三百六十九篇」，除鄒衍外尚有鄒奭（即「雕龍奭」）、公孫發、宋司星子韋等——幾乎全部亡佚

**自測**：為什麼說陰陽家「出於羲和之官」？這條說法本身出自哪部書？

### 步驟 6：鄒衍——陰陽家的集大成者

**學習目標**：掌握鄒衍的生平輪廓、著述情況與學說框架。

**子主題**

- [ ] 生平要點：齊國人（今山東東部），約生於公元前305年，卒於公元前240年前後；長期活躍於稷下學宮，是戰國後期最負盛名的學者之一。  
- [ ] 外號“談天衍”：齊人諺語「談天衍，雕龍奭」，形容他一開口便是天地開辟、時空格局。  
- [ ] 傳奇際遇：遊魏、趙、燕諸國皆受極高禮遇；燕昭王曾「擁彗先驅」（親自持掃帚為其清道），築碣石宮拜他為師——與孔孟周遊列國處處碰壁恰成對照，可見其學說對戰國君主吸引力之大。  
- [ ] 著述與命運：著《終始》《大聖》等篇共十萬餘言，《漢書·藝文志》著錄為《鄒子》四十九篇、《鄒子終始》五十六篇——**今全部亡佚**。  
- [ ] 學說總綱（下一階段逐一精讀）：深觀陰陽消息 → 五德終始（歷史觀）→ 大九州（空間觀）。  
- [ ] 容易忽略的一點：《史記》明說他立說的歸宿「必止乎仁義節儉，君臣上下六親之施」——宇宙論只是框架，最終落點仍在政治倫理，並非純談自然。  

**配套原典**：《史記·孟子荀卿列傳》鄒衍部分（陰陽家最核心的傳記材料，本步驟通讀即可，步驟10再回來精讀）。  

**任務**：為鄒衍寫一張兩百字小傳卡（生卒、國籍、外號、三大學說、著述下落）。  

**自測**：為什麼燕昭王對一個「談天說地」的學者如此禮遇？他的學說對君主究竟有什麼用？

## 階段三：三大學說精讀

> 這是全清單的核心。鄒衍的著作雖已亡佚，但三大支柱學說在《史記》《呂氏春秋》中留下了可靠記載。學完本階段，"五德終始"、"大九州"、"陰陽消息"對你來說應當是三個能隨口講清的故事。

### 步驟 7：五德終始說——用五行解釋王朝興替

**學習目標**：完整複述五德終始的運作邏輯與黃帝以來的德運序列。

**子主題**

- [ ] 核心命題：天地間有五行之"德"，輪流當令；每個王朝各應一德，德運將盡，必有新德起而代之——歷史不是雜亂無章，而是按五行**相勝**的順序循環運轉
- [ ] 標準序列（據《呂氏春秋·應同》）：黃帝土德（天先見大螾大螼，色尚黃）→ 禹木德（草木秋冬不殺，色尚青）→ 湯金德（金刃生於水，色尚白）→ 文王火德（赤烏衔丹書集於周社，色尚赤）→ **代火者必將水**（色尚黑）
- [ ] "符應"機制："凡帝王者之將興也，天必先見祥乎下民"——新王朝興起前，天必先降祥瑞示警。這套"天命預告"機制是五德終始說最有政治魔力的部分
- [ ] 歷史哲學的高度：鄒衍把王朝興替從"人事偶然"改寫成"自然必然"，這是中國最早成體系的歷史規律論，深刻影響了此後兩千年的王朝合法性敘事
- [ ] 首次實戰：秦始皇全面採納——"周得火德，秦代周德，從所不勝"，故秦自居水德（詳見步驟 12）

**配套原典**（本步驟的重點，務必精讀）：《呂氏春秋·應同》全文——五德終始說現存最完整的表述；《史記·封禪書》“秦文公出獵，獲黑龍”段落  

**任務**：合上材料，把黃帝 → 禹 → 湯 → 文王 →（秦）的德運、符瑞、尚色畫成一張表。  

**自測**

1. 五德終始使用的是相生還是相勝序列？ 為什麼這一選擇對政治敘事特別有用？  
2. 秦為什麼自認水德？ 根據這一認知，它做了哪些“配套”改動？  

### 步驟 8：大九州說——先秦最壯闊的世界想像  

**學習目標**：能畫出大九州的層級結構，並說明其思想意義。

**子主題**

- [ ] 三層結構（據《史記》轉述）：
1. 中國 = 赤縣神州，內有九州（即大禹所序之九州）
2. 像赤縣神州這樣的“州”，天下共有九個，各有“裨海”環繞，州與州之間“人民禽獸莫能相通”
3. 九州之外更有“大瀛海”環抱，“天地之際焉”
- [ ] 關鍵一句：《史記》稱“中國者，于天下乃八十分居其一分耳”——中國只是天下的八十分之一，這在當時是石破天驚的空間觀
- [ ] 方法論特色：“先驗小物，推而大之，至於無垠”——由小及大的類推法，與五德終始“先序今以上至黃帝”的推衍手法如出一轍
- [ ] 思想史意義：把中國人的空間想象從“天下即九州”猛地擴展到近乎無限；雖屬思辨而非實測，卻展示了陰陽家宇宙論的恢弘氣魄——李約瑟對鄒衍評價極高，正著眼於此

**配套原典**：《史記·孟子荀卿列傳》“中國外如赤縣神州者九”段

**自測**：大九州說的三層結構是什麼？“裨海”與“大瀛海”有何區別？

### 步驟 9：陰陽消息與時令政治

**學習目標**：理解“消息”的確切含義，讀懂時令文獻的運作邏輯——這是陰陽家最“日常”的一面，也是司馬談肯定其“序四時之大順”的部分。

**子主題**

- [ ] 「消息」釋義：陽生為「息」，陰生為「消」；陰陽二氣此消彼長，形成四時循環——「消息」說的正是時間的節律
- [ ] 時令政治的綱領：人事必須與天時同步——天子何時居何室、衣何色、行何政皆有對應；順之則治，逆之則災
- [ ] 樣板文獻一：《管子·五行》——提出「人與天調」，把一年三百六十日平分給五行，每「行」當令七十二日，各有應行之政令
- [ ] 樣板文獻二：《禮記·月令》（與《呂氏春秋·十二紀》大同小異）——逐月規定天子的居處、車旗、服色、政務，並警告「違時」的政治後果；精讀「孟春之月」一篇即可舉一反三
- [ ] 深層邏輯：這其實是「天人感應」的雛形——天時與人事構成一個必須同步聯動的系統（漢代董仲舒將把它推向極致，見步驟 14）
- [ ] 擴展：後世易學的「十二消息卦」用十二組卦象表示一年陰陽消長，可視為此說的圖像化延伸（初學了解即可）

**配套原典**：《禮記·月令》「孟春之月」全篇；《管子·五行》開頭部分

**任務**：從《月令》「孟春之月」裡摘出所有五行配伍（時節、帝、神、蟲、音、味、祭臟、居處、服色），填進你在步驟 2 做的配伍表。

**自測**：為什麼司馬談一面批評陰陽家「多忌諱」，一面又說其「序四時之大順，不可失也」？

### 步驟 11：面對亡佚——輯佚與佚文的世界

**學習目標**：了解「失傳的學派」如何被研究，掌握最基本的輯佚常識，並對網上真假難辨的「鄒子曰」保持警惕。

**子主題**

- [ ] 鄒衍著作雖已亡佚，但唐宋類書與古注（如《文選》李善注、《史記》三家注等）中保存了不少引文——這些碎片是重構其學說的原材料
- [ ] 清人的輯佚成果：馬國翰《玉函山房輯佚書》等輯有《鄒子》佚文，可作擴展瀏覽（不必通讀，只需知道「有這樣的書」即可）
- [ ] 方法論啟示：一個學說的存在方式，可以是完整文本，也可以是「散落在他人文本中的引用」——學陰陽家，同時也在學「如何處理殘缺史料」
- [ ] 提醒：網路上流傳的《鄒子》「原文」多為後人偽托或拼湊，引用前務必核對原始出處
- [ ] 擴展：出土文獻（如馬王堆帛書等）中的陰陽五行材料是當代研究熱點，結論多有爭議，適合完成本清單後再涉獵（可參考李零《中國方術正考》）

## 階段五：秦漢變奏——陰陽五行與帝國政治

> 戰國諸子的學說，真正變成國家制度是在秦漢。陰陽家是其中罕見的"贏家"：五德終始說直接進入王朝正統性敘事，成為秦漢政治的底層操作系統。本階段故事性最強，也最能體會"思想如何落地"。

### 步驟 12：秦朝水德——五德終始的第一次國家級應用

**學習目標**：說明秦朝如何將"水德"落實為制度與審美。

**子主題**

- [ ] 邏輯鏈：周為火德 → "代火者必將水" → 秦代周，故秦為水德
- [ ] 符瑞追認：《史記·封禪書》載秦文公出獵曾獲黑龍，被追認為"此其水德之瑞"
- [ ] 全套制度改造（《史記·秦始皇本紀》）：改以十月為歲首；"衣服旄旌節旗皆上黑"；"數以六為紀"（符、法冠六寸，輿六尺，六尺為步，乘六馬）；行政風格"剛毅戾深，事皆決於法"——連嚴刑峻法都找到了五行依據（水主陰，陰主刑殺）
- [ ] 歷史意義：民間歷史哲學第一次被帝國用作自我論證的官方框架

**配套原典**：《史記·秦始皇本紀》"始皇推終始五德之傳"段

**自測**：秦的哪些制度細節與"水德"對應？這說明陰陽家學說對政治有何種用途？

### 步驟 13：漢朝爭德——水德、土德、火德之爭

**學習目標**：梳理漢初百餘年的德運爭論，理解「改正朔、易服色」為何是頭等政治大事。

**子主題**

- [ ] 漢初因襲：高祖增立黑帝祠（北畤），漢家最初沿用秦的水德，丞相張蒼即持此說
- [ ] 第一次挑戰：文帝時賈誼、公孫臣主張漢當為**土德**、應改正朔易服色，遭張蒼抵制而擱置
- [ ] 定案：漢武帝太初元年（公元前104年）頒《太初曆》，正式改定土德——色尚黃、以正月為歲首、官印改用五字
- [ ] 再反轉：西漢末劉向、劉歆父子改用五行**相生**序列重排德運，推出漢為**火德**（"漢承堯運"）；東漢光武帝"始正火德，色尚赤"——"炎漢"之名由此而來
- [ ] 方法觀察：從相勝到相生、從土德到火德，德運方案隨政治需要不斷重排——這是審視該學說"解釋彈性"的絕佳案例

**配套原典**：《史記·歷書》《封禪書》相關段（可先讀介紹性文字，原文留待進階）

**現代論著（本步驟強烈推薦）**：顧頡剛《秦漢的方士與儒生》（通俗）；《五德終始說下的政治和歷史》（專門研究，考訂精詳）

**自測**：漢初為何在"水德還是土德"上糾纏百年？"改正朔、易服色"背後的實質是什麼？

### 步驟 14：收編與轉型——陰陽家融入儒學

**學習目標**：解釋一個悖論——陰陽家影響空前，學派本身卻在漢代消失。

**子主題**

- [ ] 董仲舒的轉化：把陰陽五行引入儒學，構建「天人感應」體系。《漢書·董仲舒傳》載其對策曰“天道之大者在陰陽”；《春秋繁露》更大量推演陰陽五行
- [ ] 災異政治學：日食、地震、水旱皆被解讀為上天對朝政的警示——陰陽家「天—人同步」的邏輯成為漢代政治的日常語法
- [ ] 諶緯的泛濫：西漢末至東漢，諶緯之學把陰陽五行推向神秘化高峰，也埋下這套知識體系聲譽受損的伏筆
- [ ] 學派的消亡與「轉世」：陰陽家作為獨立學派在漢以後不復存在，但其思想被四個方向分頭繼承——儒家（天人感應）、道教（煉養科儀）、醫學（《黃帝內經》）、方術（堪輿擇日命理）
- [ ] 一個重要的史學判斷：讀漢代以後的「陰陽五行」，要分清它是「儒家化了的」「道教化了的」還是「醫家化的」——源頭一致，流變各異

**配套原典**：《漢書·董仲舒傳》「天人三策」節選（讀“天道之大者在陰陽”前後即可）

**自測**：為什麼說陰陽家「消失」了，卻又「無處不在」？

## 階段六：文化血脈——後世影響與應用指引

> 學派雖亡，血脈猶存。本階段沿四條支流走一遍，看陰陽五行如何沉澱為中國文化的「基礎設施」；最後一步幫你把所學整理成自己的知識體系，並為繼續深入（尤其中醫與易學兩個方向）搭好路標。

### 步驟 15：支流一——中醫

**學習目標**：理解陰陽五行如何成為中醫的理論骨架，並判斷自己是否要沿此方向深入。

**子主題**

- [ ] 《黃帝內經》奠基：把陰陽五行與人體對應——五臟配五行（肝木、心火、脾土、肺金、腎水）、四時養生、經絡氣血，全部納入同一套框架
- [ ] 必背名句：《素問·陰陽應象大論》「陰陽者，天地之道也，萬物之綱紀，變化之父母，生殺之本始，神明之府也」——陰陽在此已是醫學總綱
- [ ] 中醫版陰陽的細化：表裡、寒熱、虛實——注意這是醫學化的引申，與先秦原義已有距離；回到步驟 1 的「關係論」去看它，便能豁然貫通
- [ ] 辨析視角：中醫陰陽五行是一套**解釋與診療框架**。研究其歷史與邏輯屬於文化研習；是否接受其臨床效力是另一層面的問題，二者分開對待
- [ ] 應用指引（如想深入中醫）：從《素問》前幾篇讀起（《上古天真論》《四氣調神大論》《陰陽應象大論》）；入門讀本可選中華書局三全本《黃帝內經》（姚春鵬譯注），再配一部現代中醫基礎教材對照閱讀

**自測**：五臟與五行的對應關係是什麼？「陰陽應象」四字作何解？

### 步驟 16：支流二——曆法、節氣與民俗

**學習目標**：在日常生活中認出陰陽五行的存在。

**子主題**

- [ ] 二十四節氣：陰陽消長的刻度表——春分秋分是陰陽持平之點，夏至冬至是陰陽極盛之點，"冬吃蘿蔔夏吃薑"式的順時觀念即由此而來
- [ ] 月令傳統的民俗化：《月令》的天子時令，演變為後世的黃曆、通書、擇日與各類時忌——追根溯源都是"人事須合天時"的老邏輯
- [ ] 幹支系統：十天干、十二地支各分陰陽、各配五行，六十甲子循環紀年——生肖與本命年的五行說法即由此而來
- [ ] 堪輿（風水）：方位、五行、四時的一體化應用，其理論底盤正是陰陽家奠定的（擴展了解即可）
- [ ] 語言化石：日常語彙如"相生相克""水火不容"，以及取名習俗中的"五行缺某"——皆是這套體系的兩千年遺存

**自測**：任選一個傳統節日或民俗，分析其中的陰陽五行元素。

### 步驟 17：支流三——易學與術數（應用指引）

**學習目標**：釐清《周易》與陰陽家的關係，建立面對術數文化的健康姿態，並為可能的深入指路。

**子主題**

- [ ] 關係辨析（重要）：《周易》本為占筮之書，後列儒家經典。《易》以道陰陽沒錯，但**陰陽家不等於易學**——鄒衍的招牌是五德終始與大九州，與卦爻體系本屬兩路；到漢代孟喜、京房一系以卦氣、消息配曆法，才是兩家的合流點
- [ ] 術數的底層語言：八字、六爻、奇門、六壬、紫微諸術，皆以陰陽五行為基本語法——學過本清單，你就拿到了閱讀術數文獻的「字母表」
- [ ] 健康姿態：以歷史文化視角研讀術數（它如何形成、如何影響社會）是一回事，以信仰姿態實踐術數是另一回事；前者是學術，後者是個人選擇——本清單只帶路到前者
- [ ] 應用指引（如想深入易學）：先讀一部可靠的《周易》通識（如廖名春《周易經傳十五講》），再進階到易學史（朱伯崑《易學哲學史》）
- [ ] 應用指引（如想深入方術文化）：以文獻與文化史為綱，可讀李零《中國方術正考》；先建立「知其源流」的底子，再考慮是否接觸實踐體系
- [ ] 紅線提醒：網路上的「國學速成」「改運課程」大多混雜偽託內容；凡遇「鄒子曰」，先回步驟 11 的習慣——核對原始出處

**自測**：為什麼說「學陰陽家不等於學《周易》」？兩家的合流發生在何時？

### 步驟 18：收官——建立你自己的知識體系

**學習目標**：完成一次完整輸出，把十八個步驟整合為可隨時調用的知識結構。

**子主題**

- [ ] 輸出（三選一）：撰寫一篇兩千字的綜述《陰陽家：為王朝算命的學派》；或向朋友進行一次三十分鐘的講述；或繪製一張從「羲和之官」到「中醫—曆法—術數」的思維導圖  
- [ ] 用自己的話回答四個總問題：  
1. 陰陽家的知識底色是什麼？（天文曆法的官守傳統）  
2. 鄒衍三說各解決什麼問題？（歷史規律、空間圖景、時間節律）  
3. 它如何影響秦漢政治？（德運敘事與改正朔、易服色）  
4. 它今天還活在哪些地方？（中醫、節氣民俗、干支、術數）  
- [ ] 逐條檢查四個常見誤區，並向自己解釋錯在哪裡：  
- 陰陽家就是道教？（否：道教形成於東漢以後，陰陽家是先秦學派，僅為其思想來源之一）  
- 陰陽家就是《易經》學派？（否：見步驟 17 的辨析）  
- 五行就是五種物質元素？（否：是五種功能類別，見步驟 2）  
- 鄒衍的著作今天還能讀到？（否：全部亡佚，僅存輯佚與轉述，見步驟 11）  
- [ ] 標注自己的興趣去向：哲學史、政治文化史、中醫、易學術數、出土文獻——據此規劃下一份進階書單  

**自測（總測試，全部通過即可"畢業"）**  

1. 不看材料，複述五德終始從黃帝到秦的完整序列。  
2. 用三分鐘向完全外行的人講清「什麼是陰陽家」。  
3. 說出至少三篇你讀過的原典篇名，及其各自回答的問題。

## 附錄 B：現代論著選目

**通史與哲學史（先讀，建立坐標）**

- 馮友蘭《中國哲學簡史》相關章節——最快的學派概覽
- 葛兆光《中國思想史》第一卷——把陰陽五行放回“一般知識”的背景中理解

**專題研究（對應階段二至五）**

- 白奚《稷下學研究——中國古代的思想自由與百家爭鳴》——陰陽五行合流與稷下學宮
- 顧頡剛《秦漢的方士與儒生》——秦漢之際方士與儒生的合流，通俗經典
- 顧頡剛《五德終始說下的政治和歷史》——德運問題研究的奠基之作
- 梁啟超《陰陽五行說之來歷》——對陰陽五行說的批判性清理，與顧文合讀最能訓練史識

**外圍與延伸（對應階段六）**

- 李零《中國方術正考》——方術文化的實證研究，含出土材料
- 李約瑟《中國科學技術史》第二卷——西方科學史視角下的陰陽家（他稱之為 Naturalists），評價之高出人意料
- 廖名春《周易經傳十五講》——易學的可靠入門（若走步驟 17 的方向）

**閱讀次序建議**：先通史（馮友蘭、葛兆光），再專題（白奚、顧頡剛），後延伸（李零、李約瑟）。論著閱讀永遠排在原典選讀之後——第一手印象優先。
