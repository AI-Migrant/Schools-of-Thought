# 印度因明
*“印度因明”正好和名家是同一坐標上的話題——它是與希臘邏輯、中國名辯並列的世界三大邏輯傳統之一。 下面從四個層面講清楚。*
## 一、因明是什麼：詞義與定位
**因明**（梵文 Hetuvidyā）：“因”指推理的根據、理由，“明”即知識、學問——相當於“推理之學”。 得名緣由是：在組成論證的各要素中，“因”（理由）是核心，故稱因明。 它是古印度“**五明**”（五門學科：聲明—語言學、因明—邏輯、醫方明—醫學、工巧明—工藝、內明—自派教義）之一，內容包括兩部分：**邏輯學**（推論規則與謬誤）和認識論（量論，即知識何以成立的學說）。 它並非佛家獨創，而是導源於古印度各派無休止的論辯實踐——辯輸贏要有公共規則，這套規則被佛教瑜伽行派吸收改造後系統化，隨佛教東傳，故中文語境常稱“佛教邏輯”。 
## 二、歷史脈絡：古因明 → 新因明 → 法稱

| **階段** | **人物/文獻** | **關鍵內容** |
| :-: | :-: | :-: |
| 源頭 | 正理派（Nyāya）《正理經》，託名足目，約公元2世紀成書 | “十六句義”綱領; 四種量（現量、比量、譬喻量、聲量）; **五支作法**：宗—因—喻—合—結，屬類比推理 |
| 佛教吸收 | 龍樹先破斥（《回誦論》）; 瑜伽行派轉而吸收，《瑜伽師地論》立“七因明”，世親已有因三相雛形 | 因明成為佛教護教論辯的工具 |
| **陳那改革**（約5—6世紀，被尊為“中世邏輯之祖”） | 《正理門論》《集量論》 | 五支精簡為三支; 創九句因（檢驗理由的第二、第八句為正因）; 確立因三相; 廢“聖言量”，只認現量、比量二量——推論性質從類比升級為演繹，這是印度邏輯史上的分水嶺 |
| 法稱（7世紀） | 《釋量論》等 | 承陳那而更趨純粹演繹，其“量論”成為藏傳佛教僧人的必修學問，地位如同希臘的邏輯學教科書 |

## 三、核心理論：三支作法與因三相
《因明入正理論》開篇一頌即總綱：“**能立與能破，及似唯悟他; 現量與比量，及似唯自悟。** “（八門二益：正確的論證與駁斥使他人領悟，正確的感覺經驗與推理使自己領悟，各有真似兩種，共八門。 ）

經典論式（陳那系的標準例子）：

| **支** | **內容** | **說明** |
| :-: | :-: | :-: |
| 宗（論題） | 聲是無常 | 立論者要向敵方證成的命題 |
| 因（理由） | 所作性故 | 因為聲音是因緣造作而生的 |
| 喻（例證） | 同喻：若是所作，见彼无常，**如瓶**;异喻：若是其常，见非所作，**如虚空** | 同喻從正面顯示“所作→無常”（喻體是普遍命題，喻依是實例）; 異喻從反面排除 |

**因三相是檢驗一個“因”是否合格的三條標準：（1） 遍是宗法性——理由必須遍及宗的主詞（聲音確是所作）; （2） 同品定有性——同類的正面例子裡必須存在理由（瓶等確是所作而無常）; （3） 異品遍無性——反面例子裡理由必須完全缺席（虛空等常物絕無“所作”屬性）。 三相比量俱足，推理即有必然性。**

與之配套的是精細的謬誤論——“三十三過”：似宗九過（含現量相違、自語相違、相符極成等）、似因十四過（不成、不定、相違三類）、似喻十過。 兩個例子極有趣味：立“**一切言皆是妄**”犯“自語相違”——此言若真，本身也妄，幾乎就是希臘的“說謊者悖論”; 立“**聲是所聞**”犯“相符極成”——雙方本已同意的命題不配作論題，可見因明立宗必須“違他順自”，天然是論辯導向的體系，與亞里士多德面向科學證明的三段論氣質不同。 
##四、傳入中國的命運（這條線最值得記）**
- **兩次傳入**：第一次在6世紀前（《方便心論》472年北魏譯、《如實論》真諦譯），反響寥寥; 第二次才是決定性的——**玄奘647年譯出商羯羅主《因明入正理論》，649年譯出陳那《因明正理門論》（“因明”二字為玄奘所加），並親授講義。** 

- **唐疏系统**：弟子竞相作疏，以窥基《因明入正理论疏》（《因明大疏》）集大成；653年日僧道昭入唐受学，归国开日本法相宗，717年玄昉携《大疏》东渡，因明在日本传承不断（善珠《明灯抄》为枢纽），而宋元以后汉地因明随唯识宗衰微成为绝学，**《大疏》在中土失传**。

- **近代回流**：1895年楊仁山（楊文會）從日本取回《大疏》，金陵刻經處重刊，才有了章太炎、熊十力《因明大疏刪注》、呂澂、虞愚一系的近代因明學復興。 

- **藏傳一支**：藏傳以法稱“量論”為一切學術之基，宗喀巴以後格魯派寺院須以多年修習《釋量論》，因明因此在藏地活成了“活的學問”。 

- 附帶一個名場面：玄奘歸國前在曲女城無遮大會立“真唯識量”，懸論十八日無人能破——正是用這套三支作法。

## 五、回到名家：三大邏輯傳統的對照

|| **希臘** | **印度** | **中國** |
| - | :-: | :-: | :-: |
| 代表 | 亞里士多德三段論 | 因明（陳那三支） | 名辯之學（名家、墨辯） |
| 關切點 | 演繹證明的形式 | 論辯規則 + 知識論（現量/比量） | **名實關係**（名家）、**故理類推論（墨辯）** |
| 論式 | 大前提—小前提—結論 | 宗—因—喻（結論前置、有立敵雙方） | 无固定论式，重“以名举实，以辞抒意，以说出故” |
| 歸宿 | 發展為形式科學 | 經玄奘入華、入藏、入日 | 名家早衰，墨辩中绝，清谈之余几成绝学 |

由此可以給名家一個更精確的定位：名家類似於希臘的智者與芝諾——長於概念與語義的批判性辨析（白馬非馬、合同異），卻沒有發展出像因明三支那樣的成熟推論理論; 真正與因明對得上的中國體系是墨家的墨辯。 近代章太炎《原名》正是拿因明三支來疏解墨辯與名學，熊十力更想合中、印、西三者撰一部《量論》——名家、因明、邏輯由此在20世紀完成了一次會師。 一句話概括二者分工：**名家追問“名與實如何對應”（語義學問題），因明追問“如何用名與言可靠地論證他人”（論證理論與知識論問題）**。 

*如果想繼續深入，可以往兩個方向走：一是精讀“白馬非馬”的論證結構並與因明的宗因喻逐句對照; 二是看墨辯“故、理、類”三物與因三相、三段論的術語對勘——這兩條都是章太炎以來名辯學研究的經典路徑。*
